# 👁️ AI Image Classification System

A Computer Vision and Deep Learning application that classifies uploaded images using a pre-trained Convolutional Neural Network.

---

## 🚀 Project Overview

Image classification is an important application of Artificial Intelligence and Computer Vision.

This project allows users to upload an image and uses a Deep Learning model to identify the objects present in the image.

The system uses transfer learning through a pre-trained MobileNetV2 model.

---

## 🧠 AI Technology

### Computer Vision

Computer Vision enables computers to analyze and understand visual information.

### Deep Learning

Deep Learning models use neural networks to learn patterns from large datasets.

### Convolutional Neural Networks

CNNs are commonly used for image processing tasks.

---

## 🤖 Model Used

### MobileNetV2

MobileNetV2 is a lightweight Convolutional Neural Network designed for efficient image classification.

The model is pre-trained on the ImageNet dataset.

The application uses the model to predict the top objects found in an uploaded image.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AI-Image-Classification-System.git
```

Move into the project directory:

```bash
cd AI-Image-Classification-System
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
