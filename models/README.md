# Deep Learning Model

This project uses a pre-trained Deep Learning model for image classification.

## Current Model

MobileNetV2

## Model Type

Convolutional Neural Network (CNN)

## Deep Learning Framework

TensorFlow / Keras

## Training Dataset

ImageNet

## Model Capabilities

The model can classify thousands of object categories.

Examples include:

- Animals
- Vehicles
- Electronics
- Household objects
- Food items
- Natural objects

## Future Improvements

Future versions can include:

- Custom CNN models
- Transfer learning
- Custom dataset training
- Object detection
- Face detection
- Image segmentation
